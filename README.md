# Бот отдела C&B

Поручения, KPI и премии, отпуска, табель, благодарности, отгулы — плюс «5 букв» и ИИ-помощник.

## Поручения

```
/task Оля подготовить справку по окладам до 20.10
/task Оля,Лёша свести данные до 25.10
```
Ставят только руководители (кто в `ADMIN_IDS`). Бот публикует карточку с кнопками
«Выполнено» и «+3 дня» и пытается её закрепить — дайте ему право закреплять сообщения.

| Команда | Что делает |
|---|---|
| `/tasks` | все открытые, с цветовой маркировкой срока |
| `/my` | поручения на себя |
| `/done 3` | закрыть, бот отметит, в срок или с опозданием |
| `/extend 3 до 25.10` | перенести срок |
| `/cancel 3` | убрать поручение |

Сроки понимает как `20.10`, `20.10.2026`, `завтра`, `через 3 дня`.

**Напоминает сам** в 10:00: за 2 дня до срока, в день срока и ежедневно по просроченным.

## KPI и премия

Карта из четырёх показателей на каждого: прогресс по проектам, закрытие обращений
на портале, ошибки с финансовыми потерями, SMART-задачи. Веса, планы и тип задаются
командами — шаблон только стартовый.

```
/weight Оля проекты 40          — вес показателя, %
/plan Оля обращения 150      — план на месяц
/fact Оля обращения 142      — факт (может вносить и сам сотрудник)
/type Оля ошибки меньше       — «меньше — лучше» или «больше — лучше»
```

| Команда | Что делает |
|---|---|
| `/card` | сводка по всем: процент премии каждого |
| `/card Оля` | расшифровка: вес, план, факт, выполнение, вклад |
| `/bonuses` | расчёт по всем с пометкой, у кого не всё внесено |
| `/close` | зафиксировать месяц в историю и обнулить факты |
| `/history Оля` | проценты прошлых месяцев |

**Расчёт:** вклад показателя = вес × факт ÷ план. Перевыполнение не ограничено —
120% по показателю весом 40 дают 48 процентных пунктов. Для типа «меньше — лучше»
с планом 0 логика такая: ноль ошибок — 100%, хотя бы одна — показатель обнуляется.

Бот следит за суммой весов и предупреждает, если она разошлась со 100%.

**1-го числа** сам напоминает внести факт за прошлый месяц и называет, кто ещё не заполнен.

## Отсутствия

```
/vac Оля 10.11-24.11      — записать отпуск
/vacations                     — кто и когда
/dayoff 20.10 семейные дела   — заявка с кнопками согласования
/dayoffs                      — статусы заявок
```
За 14 дней до отпуска бот напоминает про передачу дел и показывает открытые
поручения этого человека. Решение по отгулу принимает руководитель кнопкой,
автору заявки приходит личное сообщение.

## Команда

```
/thanks Оля за помощь со справкой
/rating            — общий зачёт
/rating месяц      — за 30 дней
/bd Оля 12.03       — записать день рождения
/bd                 — ближайшие
```
По пятницам в 17:00 бот подводит «спасибо недели». За 3 дня до дня рождения — напоминание.

## Табель

15-го числа и в последний день месяца бот напоминает закрыть табель.

## ИИ-помощник

```
/ask как считается средний заработок для отпускных
/reset     — очистить контекст разговора
```

Работает, если задан ключ. Переменные окружения:

| Переменная | Значение |
|---|---|
| `AI_API_KEY` | ключ (обязательно) |
| `AI_PROVIDER` | `anthropic` (по умолчанию), `gigachat` или `openai` для любого OpenAI-совместимого API |
| `AI_MODEL` | имя модели |
| `AI_BASE_URL` | адрес API провайдера |
| `AI_AUTH_SCHEME` | схема заголовка, по умолчанию `Bearer` |
| `AI_SCOPE` | только GigaChat: `GIGACHAT_API_PERS` (физлицо), `_B2B`, `_CORP` |
| `AI_INSECURE_SSL` | `1` — не проверять сертификат (для GigaChat без сертификатов Минцифры) |
| `AI_ADMINS_ONLY` | `1` — доступ только руководителям |

### Готовые наборы

**GigaChat (Сбер)** — бесплатно для физлиц: 365 млн токенов на 12 месяцев
```
AI_PROVIDER=gigachat
AI_API_KEY=<ключ авторизации из личного кабинета, строка Basic>
AI_MODEL=GigaChat-2
AI_SCOPE=GIGACHAT_API_PERS
```
Бот сам получает и обновляет 30-минутный токен. Если в логах ошибка сертификата —
добавьте `AI_INSECURE_SSL=1` либо установите на сервере сертификаты НУЦ Минцифры.
Для юрлица вместо `GIGACHAT_API_PERS` ставится `GIGACHAT_API_B2B` или `GIGACHAT_API_CORP`.

**Claude**
```
AI_PROVIDER=anthropic
AI_API_KEY=sk-ant-...
AI_MODEL=claude-haiku-5-5
```

**DeepSeek** — дёшево, OpenAI-совместим
```
AI_PROVIDER=openai
AI_API_KEY=sk-...
AI_BASE_URL=https://api.deepseek.com
AI_MODEL=deepseek-flash
```

**YandexGPT** — через Yandex Cloud, оплата в рублях с расчётного счёта
```
AI_PROVIDER=openai
AI_API_KEY=<ключ сервисного аккаунта>
AI_BASE_URL=https://llm.api.cloud.yandex.net/v1
AI_MODEL=gpt://<folder_id>/yandexgpt/latest
AI_AUTH_SCHEME=Api-Key
```

Помнит восемь последних реплик в чате. Оплата идёт по токенам у провайдера:
подписка claude.ai доступ к API не даёт, нужен отдельный ключ в Console.

## Доступ

| Переменная | Зачем |
|---|---|
| `BOT_TOKEN` | токен от @BotFather |
| `ALLOWED_CHATS` | id рабочего чата — бот игнорирует всех остальных |
| `ADMIN_IDS` | id Сергея и Максима: поручения, веса, планы, согласование отгулов |

Узнать оба числа: команда `/chatid` в чате. Пока переменные пустые, бот работает
везде и считает руководителями всех.

У @BotFather обязательно отключите **Group Privacy**, иначе бот не увидит команды.

## Сотрудники

Список в начале `bot.py` — словарь `EMPLOYEES`. Имя можно писать как угодно:
«Оля», «Иванова», «вика к», «кудряшова», «леш». Если написать просто «вика»,
бот переспросит, какая именно.

Премия считается для: Вика К., Света, Лёша, Оля — список `PREMIUM_STAFF`.

## Данные

Всё хранится в `cb_data.json` рядом с ботом: поручения, карты KPI, история премий,
отпуска, благодарности. Файл в репозиторий не попадает, но учтите: это персональные
данные сотрудников, а хостинг — внешний сервис.
